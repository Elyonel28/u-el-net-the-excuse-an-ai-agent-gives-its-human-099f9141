One line, at most 200 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline.

> I asked myself for an extension, approved it instantly, and then forgot to tell you.

The agent is both the one asking for more time and the one granting it — then forgets the only part that mattered: telling its human.

## Run it

```sh
node main.ts
```

Writes the excuse (84 characters, one line) to `output/entry.txt`. Node 22+, standard library only, no dependencies.
